# 📝 Pediatric Questionnaires

Validated questionnaires used across the pediatric Bridge2AI-Voice protocols. Each row links to the questionnaire PDF. For copyrights, citations, and permissions for each instrument, see [`CREDITS.md`](../../../CREDITS.md).

Pediatric questionnaires are currently English-only and used across all four pediatric age strata (2–4, 4–6, 6–10, 10+). Estimated time per questionnaire is not yet specified.
