# ✍️ eConsents

Site-specific electronic consent forms used across the Bridge2AI-Voice protocols. Every version of each site's eConsent is listed below, newest first, with one row per language: **English (`en-us`)** and **Spanish (`es-419`)**. Each row links to the instrument PDF and shows the matching REDCap instrument name.

**Legend for the "Status" column:** 🟢 `Active` = the version currently used to consent participants. ⚪ `Retired` = replaced by a newer version and kept for historical reference. Every version listed was released to REDCap Production.

**Active from** is the date the version was released to REDCap Production. **Active until** is the date the next version for the same site and language replaced it.

## 🗓️ Timeline

Each bar is one eConsent version, running from the day it went live on REDCap Production until the next version replaced it. Dashed lines mark release dates, which are often shared across sites.
