# Tiempo máximo de fonación

![recording_1][recording_1]

Esta tarea nos ayuda a analizar cómo su respiración está conectada con su voz.

Respire profundamente, presione el botón de grabar y mantenga el sonido de “aah” el mayor tiempo posible hasta que se quede sin aire. Intente mantenerlo hasta que la barra de progreso llegue al final de la pantalla.
