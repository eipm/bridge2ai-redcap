No conozco esta palabra, siguiente

A continuación, se le proporcionará una serie de palabras. Puede que conozca o no la palabra.

Si conoce la palabra, por favor proporcione una definición de la misma. Después de definir la palabra, presione **"Siguiente Palabra"**.

Si NO conoce la palabra, presione **"No conozco esta palabra, siguiente"** y se le proporcionará una nueva palabra.

Una vez que se hayan definido 6 palabras, aparecerá el botón “Tarea Completada”.
